# NAE25 — Jupyter Book

A Jupyter Book documenting Mike Mossing's bicycle journey from Puerto Vallarta, Mexico to Panama City, Panama — Stages 83–128 of the TDA Global Cycling North American Epic, ridden as a sectional participant from 25 October to 21 December 2025.

**46 riding days · 12 rest days · 7 countries · ~4,600 km · +47,060 m elevation**

## What's Been Built

### Book structure

- `_config.yml` / `_toc.yml` — Jupyter Book config with 7 country chapters and 2 appendices
- `content/index.md` — homepage
- `content/intro.md` — ride overview with stats table and data sources

### Block pages (auto-generated)

11 section pages in `content/sections/block_*.md`, one per block of consecutive riding days. Each page has:
- Interactive topo map (Folium HTML iframe, served from `content/maps/`)
- Sequential elevation profile PNG across all stages in the block
- Stage-by-stage table (distance, elevation gain, moving time, avg HR)
- `## Notes` placeholder for narrative (not yet written)

Generated by `scripts/build_pages.py` from templates + `data/processed/stages.csv`.

### Appendix — Strava Rides

`content/strava_rides.md` — all 46 stages embedded as Strava activity widgets using the
`<div class="strava-embed-placeholder">` method. The embed script is loaded via `extra_footer`
in `_config.yml`:

```yaml
html:
  extra_footer: |
    GPS data © Strava · Map tiles © OpenTopoMap (CC-BY-SA)
    <script src="https://strava-embeds.com/embed.js"></script>
```

> **Note:** Use `strava-embed-placeholder` divs, NOT raw `<iframe>` tags. Direct iframes are
> blocked by Strava's CSP. The embed.js script handles iframe injection dynamically.

### Appendix — Route Notes

8 POI guide files in `content/planning/nae25_stages_*_poi.md`, covering stages 96–128.
Each has a route overview table, stage-by-stage highlights, and points of interest.
Stages 83–95 (first three Mexico blocks) have no POI guides.

### Data pipeline

```
scripts/processing/strava_sync.py     # download activity JSON from Strava API
scripts/processing/stages.py          # aggregate per-stage metrics → data/processed/stages.csv
scripts/processing/blocks.py          # aggregate per-block metrics → data/processed/blocks.csv
scripts/visualization/render_blocks.py # generate folium maps + elevation PNGs → content/maps/
scripts/build_pages.py                # render section markdown from templates
```

Strava OAuth token is read from `~/.strava_mcp_token.json`. `STRAVA_CLIENT_ID` and
`STRAVA_CLIENT_SECRET` must be set in `.env`.

### Styling

`_static/custom.css` — makes Strava embed iframes responsive (overrides fixed widths set by embed.js).

## Build

```bash
pip install -r requirements.txt

# Regenerate data (only needed if Strava activities change)
python -m scripts.processing.strava_sync
python -m scripts.processing.stages
python -m scripts.processing.blocks

# Regenerate maps and elevation profiles
python -m scripts.visualization.render_blocks

# Regenerate section pages
python -m scripts.build_pages

# Build the book
jupyter-book build .

# Serve locally (required for Strava embeds — file:// URLs are blocked by Strava's CSP)
python -m http.server 8765 --directory _build/html
```
